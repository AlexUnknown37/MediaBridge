# MediaBridge 0.3.1

## What's new

- Added the installed MediaBridge version to the Windows tray and browser control page.
- Added automatic checks for newer packaged GitHub releases. Windows shows a tray notification; the control page shows a download link. Updates are never installed automatically.
- Improved the Pacific Drive radio WAV stream pause/resume behavior: the stream stays connected and resumes from live audio instead of replaying audio buffered during a pause.

## Downloads

- `MediaBridge-v0.3.1-windows-x64.zip`: Windows 10 (version 2004) or newer, and Windows 11.
- `MediaBridge-v0.3.1-linux-x64.zip`: Linux x64, including Steam Deck.

Both archives contain a single self-contained app binary; no .NET runtime installation is needed.
