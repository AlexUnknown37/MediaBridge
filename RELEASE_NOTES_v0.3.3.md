# MediaBridge 0.3.3

## What's fixed

- The browser control page no longer shows an "Update available" box when you're already up to date, and Windows no longer shows the "Linux extras" box.

This release also includes everything from 0.3.2:

- A red **Quit MediaBridge** button on the control page (`http://127.0.0.1:48902/`), with a confirmation first. On Linux and Steam Deck, where MediaBridge has no tray icon, this is the easy way to close it.
- Album art on Linux for apps installed as Flatpaks, such as Chrome on Steam Deck.
- A bigger README section on Linux automatic routing.

## Downloads

- `MediaBridge-v0.3.3-windows-x64.zip`: Windows 10 (version 2004) or newer, and Windows 11.
- `MediaBridge-v0.3.3-linux-x64.zip`: Linux x64, including Steam Deck.

Both archives contain a single self-contained app binary; no .NET runtime installation is needed.
